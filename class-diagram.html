Kelas, atribut, method, dan hubungannya

Lembar C-01

Setiap model menyimpan data sekaligus menyediakan operasi untuk mengelolanya. Garis pemisah pada kotak membedakan atribut dari method.

Buka gambar di tab baru ↗

Enam model dan dua tabel penghubung. Model mewarisi operasi umum seperti create(), update(), dan delete() dari kelas abstrak Model. Diagram menampilkan method utama dan sebagian operasi warisan yang digunakan. Parameter dengan nilai bawaan tidak diuraikan. rule_premis dan kerusakan_sparepart adalah tabel penghubung, bukan model PHP yang memiliki method sendiri.

  • + dan − Method publik (+) dapat dipakai pemanggil; method privat (−) hanya dipakai di dalam model. Semuanya bergaris bawah karena merupakan method statis, sehingga dipanggil dengan NamaModel::method().
  • 1 → 0..* Satu objek dapat berhubungan dengan nol atau lebih objek lain.
  • 0..1 Hubungan bersifat pilihan dan boleh belum diisi.
  • Garis tidak menunjukkan urutan kerja. Rincian hubungan tersedia pada tabel di bawah.

Atribut dan method setiap kelas

User

Atribut berisi identitas akun, kata sandi terlindung, kontak, jenis akun, status aktif, waktu masuk terakhir, serta waktu pencatatan dan perubahan.

Satu akun boleh memiliki banyak konsultasi. Riwayat tidak ikut dihapus ketika akun dihapus; user_id pada riwayat menjadi kosong.

Method yang tersedia

  • + register(data: array): int
  • + rules(ignoreId: ?int, passwordRequired: bool): array
  • + update(id: int, data: array): void
  • + withKonsultasiCount(): array

Konsultasi

Atribut mencakup kode, pemilik akun, data motor, dugaan awal, gangguan akhir, aturan yang digunakan, jawaban, jejak pemeriksaan, status, total biaya, dan tanggal pengerjaan.

Dugaan awal dan gangguan akhir disimpan terpisah. Keduanya boleh kosong jika belum dipilih atau belum ada yang cocok.

Method yang tersedia

  • + generateKode(): string
  • + detail(id: int): ?array
  • + filtered(filter: array): array
  • + update(id: int, data: array): void
  • + stats(userId: ?int): array
  • - filterClause(f: array): array

Gejala

Atribut mencakup kode, nama, kalimat pertanyaan, kategori, dan waktu pencatatan.

Satu gejala dapat digunakan pada banyak aturan melalui tabel rule_premis.

Method yang tersedia

  • + rules(ignoreId: ?int): array
  • + keyed(): array
  • + withUsage(): array
  • + create(data: array): int

Kerusakan

Atribut mencakup kode, nama, jenis servis, biaya jasa, penjelasan masalah, dan tindakan perbaikan.

Method spareparts(), syncSpareparts(), dan estimasi() mengatur anjuran suku cadang serta biaya melalui tabel kerusakan_sparepart.

Method yang tersedia

  • + spareparts(kerusakanId: int): array
  • + syncSpareparts(kerusakanId: int, items: array): void
  • + estimasi(kerusakan: array): array
  • + summary(): array

Rule

Atribut mencakup kode, gangguan tujuan, keterangan, status aktif, dan waktu pencatatan.

Hanya aturan aktif yang dipakai untuk memeriksa jawaban. Method save() menyimpan aturan beserta susunan premisnya dalam satu transaksi.

Method yang tersedia

  • + withPremis(onlyActive: bool): array
  • + findWithPremis(id: int): ?array
  • + save(id: ?int, data: array, premisIds: array): int
  • + duplicateOf(kerusakanId: int, premisIds: array): ?string
  • + toText(rule: array, withNames: bool): string

rule_premis

Tabel penghubung berisi rule_id, gejala_id, dan urutan pertanyaan.

Bukan model PHP dengan method sendiri. Isinya dibuat dan diubah oleh Rule::save().

Tabel penghubung: tidak memiliki kelas model maupun method sendiri.

Sparepart

Atribut mencakup kode, nama, satuan, harga, jumlah persediaan, dan waktu pencatatan.

Method withUsage() membantu membaca pemakaian pada anjuran, sedangkan lowStock() menemukan persediaan yang perlu diperiksa.

Method yang tersedia

  • + rules(ignoreId: ?int): array
  • + withUsage(): array
  • + lowStock(threshold: int): array
  • + update(id: int, data: array): void

kerusakan_sparepart

Tabel penghubung berisi kerusakan_id, sparepart_id, dan jumlah pemakaian.

Bukan model PHP dengan method sendiri. Isinya dibaca oleh Kerusakan::spareparts() dan diatur oleh Kerusakan::syncSpareparts().

Tabel penghubung: tidak memiliki kelas model maupun method sendiri.

Arti hubungan antarobjek

HubunganJumlah kaitanPenjelasan
Akun dan konsultasiSatu akun dapat memiliki nol atau banyak konsultasi.Konsultasi dapat kehilangan pemilik akun jika admin menghapus akun, tetapi riwayatnya tetap tersedia.
Konsultasi dan dugaan awalSatu konsultasi dapat memilih satu dugaan gangguan atau belum memilih.Belum memilih berarti semua kemungkinan dapat diperiksa.
Konsultasi dan gangguan akhirSatu konsultasi dapat berakhir dengan satu gangguan yang cocok atau tanpa hasil.Gangguan yang cocok dapat muncul pada banyak konsultasi.
Konsultasi dan aturanKonsultasi yang selesai dapat menyimpan satu aturan yang digunakan.Aturan yang sama dapat digunakan pada banyak konsultasi.
Gejala dalam aturanSetiap bagian aturan menunjuk satu gejala dan satu aturan.Susunan bagian menentukan urutan pertanyaan yang ditampilkan.
Gangguan dan aturanSetiap aturan memiliki satu gangguan tujuan.Satu gangguan dapat memiliki beberapa aturan yang berbeda.
Gangguan dan anjuran suku cadangSatu gangguan dapat memiliki nol atau banyak anjuran.Anjuran menyebut suku cadang beserta jumlah pemakaiannya.
Suku cadang dan anjuranSatu suku cadang dapat muncul pada nol atau banyak anjuran.Jumlah pemakaian dihitung khusus untuk setiap gangguan.
